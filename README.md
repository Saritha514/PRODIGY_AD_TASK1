# PRODIGY_AD_TASK1
🧮 Colorful Calculator Android Application
📌 Project Overview

The Colorful Calculator Web Application is a responsive and user-friendly basic calculator developed using HTML, CSS, and JavaScript. It allows users to perform fundamental arithmetic operations such as addition, subtraction, multiplication, division, and percentage calculations through an attractive and interactive interface.

This project was developed as part of my internship to strengthen my front-end development skills and gain practical experience in designing functional web applications.

The application focuses on simplicity, usability, and visual appeal, making it suitable for both desktop and mobile devices.

🎯 Objectives

The main objectives of this project are:

To design a functional web-based calculator

To implement arithmetic logic using JavaScript

To create a responsive and attractive UI using CSS

To enhance problem-solving and programming skills

To gain hands-on experience in front-end development

To apply internship learning outcomes in a real project

✨ Features

🧮 Performs basic arithmetic operations (+, −, ×, ÷)

📊 Supports percentage (%) calculations

🔢 Decimal number support

🎨 Colorful and modern user interface

📱 Fully responsive design for mobile devices

⚡ Fast and real-time calculations

🧹 Clear (C) button to reset input

❗ Error handling for invalid expressions

🛠️ Technologies Used

Frontend: HTML5, CSS3, JavaScript

Styling: CSS Grid, Gradients, Transitions

Logic: JavaScript eval() function

Environment: Modern Web Browsers
